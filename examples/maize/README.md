# Runnable maize sequence example: B73 versus Ames21814

All input files are included in `data/`. No full-genome download, external server, account, or manual configuration editing is required to run this example.

```bash
conda activate indelmarker
bash scripts/run_examples.sh --suite maize --cores 2
```

## Source and provenance

| Input | Published assembly | Original interval, 1-based inclusive |
| --- | --- | --- |
| B73 reference | Zm-B73-REFERENCE-NAM-5.0 | chr3:194,750,001–195,050,000 |
| Ames21814 query | Zv-Ames21814-REFERENCE-CEMPS-1.0 | chr3:199,705,286–200,083,834 |

Source downloads: [B73](https://download.maizegdb.org/Zm-B73-REFERENCE-NAM-5.0/), [Ames21814](https://download.maizegdb.org/Zv-Ames21814-REFERENCE-CEMPS-1.0/). B73 gene models use `Zm-B73-REFERENCE-NAM-5.0_Zm00001eb.1.gff3`. The longest CDS per complete gene is extracted from the B73 sequence. Both bundled nucleotide extracts were checked against their MaizeGDB online sequences during preparation.

MaizeGDB notes that its Ames21814 sequence is not identical to the GenBank sequence: use the exact source/version above. See its [README](https://download.maizegdb.org/Zv-Ames21814-REFERENCE-CEMPS-1.0/Zv-Ames21814-REFERENCE-CEMPS-1.0.README).

`provenance.json` records the sources, offsets, gene list, simulation parameters, and SHA-256 hashes of bundled input files. `B73.original_gene_coordinates.tsv` preserves original genomic coordinates. Source assemblies are unmodified; only local FASTA identifiers are renamed `chr3_example`.

## What the three strategies demonstrate

| Strategy | Data type | Verified output |
| --- | --- | --- |
| I | Real public assembly extracts | Two natural InDels, 144 and 241 bp; two rows with usable primer designs |
| II | **Simulated** paired 150-bp reads from unmodified real B73/Ames21814 haplotype extracts | Three 20–100-bp contrasting InDels and usable primer designs, including the 42-bp deletion near local position 3,792 |
| III | Real public genome extracts and B73 gene models | Ten gene alignments, each containing both B73 and Ames21814 sequences |

The Strategy I example deliberately uses a **100–500-bp** filter: this small region contains no 300–500-bp calls in the tested run. The production configuration still defaults to 300–500 bp. These examples demonstrate changing a filter to match the available sequence variation and planned assay, not a fixed marker yield.

For Strategy II, the bundled haplotypes are the first 12,000 bases of each assembly extract. They correspond to B73 chr3:194,750,001–194,762,000 and Ames21814 chr3:199,705,286–199,717,285. Reads are generated by tiling distinct variable-length fragments (350–550 bp), with fixed random seeds and matching mate identifiers. No artificial variants are inserted into these maize haplotypes. These files are **not raw sequenced WGS** and do not measure real sequencing error, genome-wide mappability, or sensitivity in repetitive regions.

## Outputs and coordinates

- Strategies I/II: `results/strategy<N>/primer3/primer_markers.xlsx`, plus VCF and QC/intermediate files.
- Strategy III: `results/strategy3/strategy3/alignment/manifest.tsv` and per-gene FASTA alignments.
- Every strategy: `results/strategy<N>/validation.json`.

For Strategy I and III, convert a B73 local position `p` to the original genome using `194750001 + p - 1`. For Ames21814, use `199705286 + p - 1`. BED coordinates are 0-based half-open; the workflow's reported gene coordinates and entered intervals are 1-based inclusive.

These are **computational worked examples**, not evidence of PCR validation and not a reproduction of the THP3 recombinant mapping experiment. A cropped reference cannot establish whole-genome primer specificity; recheck candidate primers against the full parental genomes before experimental use.

## Rebuild the bundled inputs

After obtaining the complete public assemblies and B73 GFF3, run the command in [the reproducibility guide](../../docs/REPRODUCIBILITY.md). This regenerates the nucleotide extracts, gene annotations, CDS, simulated reads, and input checksums. The full source files are optional and are not required for ordinary users of these bundled examples.
